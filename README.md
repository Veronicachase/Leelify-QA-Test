# Leelify

Repositorio organizado en dos aplicaciones:

- `front/`: interfaz React, TypeScript y Vite.
- `back/`: backend Java administrado con Maven.

El backend Node anterior se conserva temporalmente en `back/legacy-node/` como
referencia. No forma parte del backend Java activo.

## Frontend

```bash
cd front
npm install
npm run dev
```

## Backend

```bash
cd back
mvn compile
```

El skill `ui-ux-pro-max` se conserva en `front/.agents/skills/` para usarlo más
adelante en el trabajo de interfaz.
